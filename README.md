# MissAVDL - JavBus 刮削器 + N_m3u8DL 下载器

一个专为绿联 NAS 影视中心设计的综合工具，集 JavBus 元数据刮削和 N_m3u8DL 视频下载于一身。

## 功能特点

### 刮削器功能
- ✅ 符合绿联 NAS NFO 格式规范
- ✅ 生成标准 NFO 文件（兼容绿联影视中心）
- ✅ 自动下载海报和封面图
- ✅ 固定风格：**爱情(10749)** + **动作(28)**
- ✅ 支持代理设置
- ✅ 支持 SMB 网络路径输出
- ✅ 相对路径支持（通过 base_dir 配置）
- ✅ 自动从文件名提取车牌号
- ✅ 文件列表显示（已刮削/未刮削）
- ✅ 自动整理视频文件到对应目录

### 下载器功能
- ✅ 集成 N_m3u8DL 下载工具
- ✅ 支持 M3U8 链接下载
- ✅ 自动检测并下载缺失工具（N_m3u8DL、FFmpeg）
- ✅ 支持代理下载
- ✅ 支持 SMB 网络路径保存
- ✅ 本地缓存 + 自动上传到 SMB
- ✅ 自动合并 TS 分片
- ✅ 实时显示下载进度

### 工具管理
- ✅ 自动检测所需工具
- ✅ 一键下载最新版本 N_m3u8DL
- ✅ 一键下载最新版本 FFmpeg

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 启动 GUI

```bash
python gui.py
```

程序启动后包含三个主要标签页：刮削器、下载器、工具管理。

---

### 刮削器标签页

#### 配置说明

| 字段 | 说明 |
|------|------|
| **影片目录** | 输出目录，支持 SMB 网络路径 |
| **选择文件** | 下拉选择目录中的文件（已刮削/未刮削） |
| **车牌号** | 输入影片番号，如 ABC-123 |
| **媒体库根目录** | 绿联 NAS 媒体库根目录（NAS 内部路径） |
| **代理地址** | JavBus 需要代理访问 |
| **域名** | JavBus 镜像域名 |
| **超时(秒)** | 请求超时时间 |

#### 使用示例

1. **影片目录**：设置为 SMB 共享路径
   ```
   \\domain4nas\share\MissAV
   ```

2. **媒体库根目录**：设置为绿联 NAS 的媒体库根路径（NAS 内部路径）
   ```
   /volume1/share/MissAV
   ```

3. 从「选择文件」下拉框选择文件，或直接输入车牌号

4. 点击「开始刮削」

---

### 下载器标签页

#### 配置说明

| 字段 | 说明 |
|------|------|
| **M3U8 链接** | 输入视频的 M3U8 播放地址 |
| **保存目录** | 视频保存目录，支持 SMB 网络路径 |
| **文件名** | 自定义保存的文件名 |
| **Referer** | HTTP Referer 头（部分网站需要） |
| **代理地址** | 下载时使用的代理 |

#### 使用示例1

1. 输入 M3U8 链接
2. 设置保存目录（支持 SMB）
3. 可选：设置文件名、Referer、代理
4. 点击「开始下载」

#### 使用示例2（猫抓插件）

1. 在猫抓插件的解析界面点击调用m3u8DL按钮，点击预览命令，复制预览命令
2. 粘贴到「快速粘贴」区域
3. 点击解析参数
4. 可选：设置文件名、Referer、代理
5. 点击「开始下载」

---

### 工具管理标签页

自动检测并下载所需工具：
- **N_m3u8DL**：M3U8 下载工具
- **FFmpeg**：视频处理工具

点击「检测工具」查看状态，点击「下载」按钮自动安装。

## 输出文件结构

```
影片目录/
└── ABC-123/
    ├── ABC-123.nfo           # 元数据文件 (绿联格式)
    ├── ABC-123-poster.jpg    # 竖版海报 (1080x1920)
    └── ABC-123-backdrop.jpg  # 横版封面 (1920x1080)
```

## NFO 文件格式（绿联规范）

```xml
<?xml version="1.0" encoding="UTF-8"?>
<movie>
  <title>影片标题</title>
  <year>2024</year>
  <plot>影片简介...</plot>
  <releasedate>2024-01-15</releasedate>
  <genre>10749</genre>  <!-- 爱情 -->
  <genre>28</genre>     <!-- 动作 -->
  <actor>
    <name>演员名字</name>
  </actor>
</movie>
```

## 绿联影视中心使用指南

1. 刮削完成后，在绿联影视中心添加媒体库
2. 选择刮削后的影片目录
3. 勾选 **「优先读取本地信息」**
4. 扫描媒体库即可

## 注意事项

1. **代理**：JavBus 需要代理访问，请确保代理可用
   - Clash: `http://127.0.0.1:7890`
   - V2RayN: `http://127.0.0.1:10809`

2. **SMB 路径**：确保网络路径可访问和可写入

3. **风格固定**：本工具固定输出爱情+动作风格，如需其他风格请手动修改 NFO
